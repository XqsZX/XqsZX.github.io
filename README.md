# ROS2 学习笔记

记录ROS2学习过程的个人博客。

## 网站结构

```
.
├── _posts/          # 博客文章
├── _layouts/        # 页面布局模板
├── _includes/       # 可复用的页面组件
├── assets/          # 静态资源
├── _config.yml      # Jekyll配置
├── index.md         # 首页
└── about.md        # 关于页面
```

## 本地运行

```bash
bundle install
bundle exec jekyll serve
```

然后访问 http://localhost:4000
